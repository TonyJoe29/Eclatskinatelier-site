# Como Publicar Gratis

## Opcion 1: Netlify Drop

Es la forma mas rapida para empezar.

1. Abre `https://app.netlify.com/drop`.
2. Arrastra la carpeta completa `EclatSkinAtelier-site`.
3. Espera a que Netlify genere una URL.
4. Prueba la URL en celular.
5. Pega esa URL en Linktree, Instagram y Pinterest.

Ventaja: no requiere codigo ni Git.  
Desventaja: cada cambio se actualiza arrastrando la carpeta otra vez.

## Opcion 2: GitHub Pages

Mejor si quieres versionar y tener historial.

1. Crear repositorio llamado `eclatskinatelier`.
2. Subir `index.html`, `assets/`, `docs/`, `data/` y `drafts/`.
3. En GitHub: Settings > Pages.
4. Source: Deploy from branch.
5. Branch: `main`, folder `/root`.
6. GitHub dara una URL tipo `https://usuario.github.io/eclatskinatelier/`.

Ventaja: mas profesional para trabajar conmigo a futuro.  
Desventaja: requiere crear cuenta/repositorio y aprender flujo basico.

## Opcion 3: Cloudflare Pages

Buena si luego compras dominio.

1. Crear cuenta en Cloudflare.
2. Pages > Upload assets.
3. Subir carpeta `EclatSkinAtelier-site`.
4. Conectar dominio cuando lo tengas.

## Recomendacion

Para hoy: Netlify Drop.  
Para largo plazo: GitHub Pages o Cloudflare Pages.

## Despues de publicar

1. Cambiar Linktree: primer boton debe ser la nueva pagina.
2. Corregir Instagram en Linktree: debe apuntar a `https://www.instagram.com/eclat_skin_atelier/`.
3. Agregar disclosure en Linktree.
4. Crear pines que apunten directo a la nueva URL.
